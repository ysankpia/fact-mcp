# Code of Conduct

## The short version

Be decent. Assume the other person is acting in good faith. Disagree about
code, not about people.

## Scope

This applies to issues, pull requests, discussions, and any other space where
you are representing this project.

## What is not acceptable

- Personal attacks, insults, or sustained disruption
- Harassment of any kind, public or private
- Discriminatory language about who someone is
- Publishing someone's private information without permission

## Reporting

Report a problem to the maintainer through the contact on the GitHub profile.
Reports are read and handled privately. The maintainer may edit or remove
comments, and may block accounts that keep breaking this.

## Attribution

This is a short, plain-language policy rather than the full Contributor
Covenant, because this project is small. If it grows, it will adopt one.
